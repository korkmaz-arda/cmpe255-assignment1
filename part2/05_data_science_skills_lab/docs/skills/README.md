# Standalone methodology guides

Seven self-contained guides, each readable on its own. They describe the methodology this
lab actually implements - the code in `skills_lab/` is the executable version of these notes,
and every number quoted here is one the app recomputes on your machine rather than a
recorded historical figure.

| [01_exploratory_data_analysis.md](01_exploratory_data_analysis.md) | Profiling a table before modelling it |
| [02_leakage_free_preparation.md](02_leakage_free_preparation.md) | The train-only rule, and why pipelines enforce it |
| [03_feature_engineering.md](03_feature_engineering.md) | Derived features and target transforms |
| [04_imbalanced_classification.md](04_imbalanced_classification.md) | Rare positives, PR-AUC, and threshold selection |

| [06_data_quality_audit.md](06_data_quality_audit.md) | Rate-based scoring, defects versus business events |
