Architecture blueprint

Dimensions below are read from the checkpoint currently being served.

    Rotary position embeddings (RoPE)

    (x₂ᵢ, x₂ᵢ₊₁) → (x₂ᵢ cos mθᵢ − x₂ᵢ₊₁ sin mθᵢ,
      x₂ᵢ sin mθᵢ + x₂ᵢ₊₁ cos mθᵢ),  θᵢ = 10000^(−2i/d)

    Queries and keys (not values) are rotated pair by pair by an angle proportional to the position m. The dot product of a rotated query and key depends only on how far apart they are, so attention sees relative distance without a learned position table. NanoLlama rotates adjacent pairs (interleaved layout).

    SwiGLU feed-forward

    FFN(x) = W₂ ( SiLU(W₁x) ⊙ W₃x )

    Two parallel projections up to the hidden width; one goes through SiLU and gates the other by elementwise multiplication, then W₂ projects back down. All three projections are bias-free.

    KV cache

    Kₜ = [Kₜ₋₁; kₜ],  Vₜ = [Vₜ₋₁; vₜ],  attn(qₜ, Kₜ, Vₜ)

    While generating, the keys and values of earlier characters are stored per layer. Each new character runs through the network once and attends to the stored tensors instead of recomputing the whole prompt. Rotary angles are taken at the absolute position of the new character, so cached and full computations agree (verified by the test suite). The chat tab uses this path.

    RMSNorm

    RMSNorm(x) = x / √(mean(x²) + ε) · g

    Rescales each vector by its root-mean-square with a learned per-channel gain g; unlike LayerNorm it does not subtract the mean. Applied before attention, before the feed-forward block, and once before the output head.

    Glossary

    Retrain NanoLlama

    Trains a new model from random weights on the training split, picks the epoch with the best validation score, checks it with a probe, then switches the server to it. The currently served model keeps answering until the new one is promoted. Test sets are never read here; the new version is not finalized.
